# Campaign solutions — spoilers

Developer/playtester reference, excluded from the deployed site. Generated by `npm run audit:levels` from `campaign-plans.json` and successful engine replays. The prose describes one plan; alternatives can be valid. U/D/L/R move, W waits, X drops the held tool. Shortened sequences below are legal winning witnesses, not guaranteed optimal routes.
