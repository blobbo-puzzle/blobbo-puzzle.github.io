# Credits and provenance

This is an independent browser reconstruction inspired by **Blobbo**, the Macintosh puzzle game by **Glenn Andreas**. It is not an official port or an endorsed release.

**Globbo by siwu** helped demonstrate the puzzle structure and provided a playable browser reference: [Lexaloffle project](https://www.lexaloffle.com/bbs/?tid=46390).

The engine, procedural canvas artwork, synthesized sound effects, new background composition, and all shipped room layouts were created for this project. No original Macintosh executable, bitmap, sampled audio, level pack, or Globbo cartridge/code is included. References were used to study behavior, not as distributable assets.

Research links and remaining fidelity questions are recorded in [docs/research.md](docs/research.md). Original-game research screenshots and previous local builds are not part of this repository or its release archives.
