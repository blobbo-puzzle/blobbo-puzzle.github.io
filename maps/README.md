# Community maps

Original puzzle submissions are welcome, especially **Extra hard** rooms where a small set of objects hides a surprising idea.

## Submit a room

1. Open [Blobbo](https://blobbo-puzzle.github.io/), choose **Gear → Create**, and build your room.
2. Use **Test room** and finish it from a fresh start. Try the obvious approaches too: a clever-looking setup may have an accidental shortcut.
3. Choose **Export** and add the resulting file here as `your-room.blobbo.json`. One file per room; keep the exported format and use a descriptive filename.
4. Open a pull request. Include the proposed category (**Regular** or **Extra hard**), dimensions, and a short description of what makes it interesting. Put a complete winning move sequence and explanation inside a collapsed spoiler section in the PR description.

Move notation: **U/D/L/R** = directions, **W** = wait, **X** = drop the held tool. Write the sequence from a fresh start, without undo or restart.

Aim for compact layouts, objects that have multiple uses, and decisions that matter. More walking does not make a room harder. A longer solution is welcome when its steps serve the puzzle. Keep room names and descriptions free of solution hints.

Reviewers can import the JSON through **Gear → Create → Import**. Maps here are submissions and examples; accepted puzzles are added to the built-in collections after review and solution verification. You only need to submit the JSON, not edit the game engine or collection files.

## Example

[`palm-lake.blobbo.json`](palm-lake.blobbo.json) is the larger custom room shown in the README GIF. Download the raw JSON and import it to try the trees, canoe crossing and ball push. It demonstrates the file format and gadgets; it is not an Extra hard entry.
